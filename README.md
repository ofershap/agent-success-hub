# דברים שעבדו עם סוכני AI

האב קהילתי בעברית: מה ביקשנו, מה הסוכן עשה, מה עבד ומה לא. המטרה היא ללמוד מניסויים שאפשר לשחזר, לא להבטיח תוצאות.

- `docs/` אתר GitHub Pages.
- `entries/` סיפורים מאושרים בלבד, בפורמט JSON.
- `AGENTS.md` הוראות לסוכנים ולתורמים.
- `templates/entry.json` תבנית כניסה.
- `.github/ISSUE_TEMPLATE/story.yml` טופס ציבורי.
- `scripts/intake.py` סינון ראשוני ויצירת PR טיוטה באמצעות GITHUB_TOKEN.
- `SECURITY.md` מגבלות הסינון ובדיקת מנהל.

## הפעלה

נדרש Python 3 בלבד לבנייה: `python3 scripts/build.py`. בדיקות: `python3 scripts/test_content.py`.
GitHub Pages: מקור GitHub Actions. לאחר מיזוג סיפור ל-main, האתר נבנה ומפורסם אוטומטית מתיקיית `docs`. הטופס מייצר תקציר אוטומטי מקומי (קטעים קצרים מהכותרת, הבקשה, מה עבד ומה לא); מנהל בודק ומשכתב לפני המיזוג. אפשר להריץ שוב Prepare local English summary עם מספר ה-issue.
בהגדרות Actions יש לאפשר **Allow GitHub Actions to create and approve pull requests**. הבוט יוצר PR, אך אינו מאשר או ממזג. אל תפעילו auto-merge.

## שפות

עברית קודם. תקציר אנגלי קצר לכל סיפור, מסומן לפי מקורו. אין ממשק דו-לשוני מלא. תקציר צריך לשמר אי-ודאות ולא להפוך טענה להוכחה.

## מצב ההשקה

אין עדיין סיפורי קהילה מאושרים לפרסום. אין לייחס דוגמה לאדם בלי מקור ורשות. הגשת טופס דורשת חשבון GitHub ואינה מפרסמת באתר מיד.
